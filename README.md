# JobConnect 

**JobConnect** is our final project for the Web Development course. It’s a full-stack job portal web application that connects job seekers and employers in a simple and easy way.
We built it using tools like Node.js, Express, MongoDB, HTML, CSS, and JavaScript — all from scratch without any frontend frameworks!

---

## What This Project Is About

This project helped us put together everything we’ve learned. From building the backend with Express and MongoDB to creating a clean and responsive frontend using just HTML, CSS, and JavaScript.

We built:
- A full **user authentication system**
- APIs for job posting and application
- A clean and responsive user interface for both job seekers and employers

---

## Technologies Used

### Frontend:
- HTML5
- CSS3 (with Normalize.css)
- Vanilla JavaScript (ES6+)
- Flexbox & CSS Grid for layout
- Responsive design with media queries

### Backend:
- Node.js
- Express.js
- MongoDB with Mongoose
- bcrypt for password hashing
- dotenv for environment variables

---

## Key Features

### For Job Seekers:
- Login
- View all jobs
- Apply to a job
- View application status

### For Employers:
- Login
- Post new jobs
- View all posted jobs
- View applications
